## Priority Issues

### [P1] Color palette is the anti-reference
The primary palette token is teal-500 + blue-500 + purple-500 — the canonical AI-portfolio color. Requires full palette replacement in tailwind.config.js and index.css.

### [P1] Gradient text on every heading
12 usages across 7 files. Every h2 on the site uses gradient-text. Hierarchy is zero when everything is decorated. Delete gradient-text from all headings.

### [P1] ThemeParticles at count=380
380 motion.circle elements, 30fps React re-render loop, covering the entire viewport permanently. Visual AI-tell + real performance regression. Remove from App.jsx.

### [P2] Skills section undermines credibility
Progress bars with self-assigned percentages (VS Code: 95%), emoji icons, gradient fills. Replace with a 2-3 sentence technology statement + project links.

### [P2] Section filler dilutes evidence
Fun facts, competencies emoji block, FAQ, stat tiles, and three empty experience entries. Delete all. Every element that doesn't prove capability dilutes those that do.
